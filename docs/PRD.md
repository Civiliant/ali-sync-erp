## 1. 产品概述

### 1.1 产品定位
Ali-Sync 是一套面向**阿里巴巴国际站 + 1688 卖家店铺**的轻量化智能 ERP 系统，以"**一件代发财务核算**"为核心、以"**供应商档案沉淀**"为纽带、具备"**云端素材与 AI 中转基础设施**"。

核心价值：**帮老板把账算明白，帮运营把单履约好，为智能化升级铺平底层通道。**

### 1.2 目标用户与核心痛点
| 目标用户 | 核心痛点 |
|---|---|
| 多店铺国际站卖家（一件代发/轻度定制模式，如家具、家居摆件、创意用品等非标品类） | 多店铺订单数据割裂，频繁切换账号效率低下 |
| 老板（财务核算决策者） | 汇率波动无法准确核算单笔订单实际毛利；一件代发采购成本（阶梯价）、国内运费、国际运费、木架打包等多笔杂费难以归集 |
| 业务员/运营（履约执行者） | 供应商信息分散，缺少线下工厂/档口沉淀与商品追溯；缺乏图片素材统一管理与 AI 风控/刊登基础设施 |

### 1.3 业务场景（一件代发核心流程）
1. **基础建档**：同步国际站/1688 店铺商品到本地库 → 绑定供应商 → 配置阶梯采购价
2. **订单捕获**：API 自动抓取平台订单 → 订单入库并解析商品明细
3. **成本匹配**：系统根据下单数量自动命中本地商品库对应阶梯采购价
4. **多笔费用补录**：运营手动添加国内运费、打包费、国际运费等多笔动态成本（选填 1688 单号/线下收据号）
5. **利润换算**：按订单下单时间对应的历史汇率（内部记账汇率锁账快照）折算本币，扣除汇总成本得出毛利
6. **老板看板与导出**：一键导出包含完整成本明细的 Excel/PDF 财务利润表

## 2. 权限模型（可配置 RBAC，核心业务规则）

### 2.1 角色体系
- **不硬编码固定角色**：后台可自由创建角色、分配**按钮级权限点**
- **预置默认角色**：
  - **老板**：管理所有店铺（增删改查、授权、解绑），查看所有订单、商品数据；店铺管理页面仅老板可见
  - **业务员**：通过"店铺子账号绑定 ERP 员工账号"实现绑定，只能看到自己绑定店铺的订单、商品，看不到其他店铺数据
- 权限点拆分到按钮级：店铺管理、修改订单成本、导出订单、查看利润、商品上新、AI 审查等

### 2.2 数据隔离
- 所有订单、商品查询自动过滤当前用户绑定的店铺 ID；老板角色默认查看全部
- 员工所有写操作记审计日志
- 员工导出订单时，客户手机号、地址按权限打码（脱敏）

## 3. 功能模块详细规格

### 3.1 店铺管理模块（P0）
关联表：stores, platform_accounts, platform_account_bindings, alibaba_oauth_states, alibaba_oauth_logs

1. **店铺授权（OAuth 2.0）**：
   - 支持阿里国际站与 1688 店铺授权
   - 授权流程：前端"添加店铺" → 选择平台 → 跳转官方授权页 → 回调换取 access_token/refresh_token → AES-256-GCM 加密存储
   - token 自动续期：定时任务检测有效期，过期前 7 天自动刷新，刷新失败标记 REFRESH_FAILED
   - state 防 CSRF：OAuth state 存 Redis，有效期 600 秒，回调后立即删除
2. **店铺列表**：展示所有已授权店铺、平台、授权状态、到期时间
3. **店铺操作**：解绑店铺、重新授权、查看同步状态
4. **子账号绑定**：国际站同步后获取子账号，绑定 ERP 员工账号（业务员数据隔离依据）
5. **数据隔离**：所有订单、商品查询自动过滤当前授权店铺 token，不同店铺数据互不可见
6. **凭证安全**：access_token、refresh_token、app_secret 全部 AES 加密存储，禁止明文写日志、禁止返回前端

### 3.2 商品管理模块（P0）
关联表：products, product_skus, product_images, product_groups, product_platform_mappings, inventory

1. **商品同步**：按授权店铺维度一键拉取国际站在线/下架商品；列表展示主图、标题、SKU、外币售价，标注"来源店铺"
2. **本地商品库**：支持本地分类、标签、成本价历史记录
3. **平台商品映射**：1688 的 Offer SKU（Spec ID）与本地 product_skus.id 建立映射，自动同步阶梯批发价至 product_skus.wholesale_prices
4. **采购阶梯价**：支持配置阶梯采购成本（例：1-49 件￥15；50-99 件￥13；100+ 件￥10）
5. **预留扩展**：后续 AI 一键上新（本地商品上传到国际站/1688）

### 3.3 订单管理模块（P0）
关联表：orders, order_items, order_costs, shipments, shipment_items

1. **订单同步**：自动拉取国际站/1688 订单，展示订单号、来源店铺、买家信息、购买 SKU、数量、外币成交总额、平台手续费
2. **同步策略**：
   - 自动轮询：系统配置中可设置轮询间隔（5/15/30/60 分钟）
   - 手动刷新：订单列表提供"立即同步订单"按钮
3. **成本录入（核心）**：订单入库后自动匹配阶梯成本，支持手动录入**三类成本**：
   - 采购成本、运输成本、其他成本
   - 允许 [+] 添加多笔动态成本项，系统自动求和得出订单实际总成本
   - 支持 1688 采购单号/线下收据号（非必填）
4. **利润计算**：
   - 订单收入(CNY) = 销售额(USD) × 内部记账汇率（订单下单时间对应历史汇率）
   - 订单总成本(CNY) = Σ(各项动态成本)
   - 净利润(CNY) = 订单收入 − 订单总成本
   - 毛利率(%) = (净利润 ÷ 订单收入) × 100%
   - 订单列表、订单详情都要显示利润字段
5. **汇率锁账快照**：订单进行利润核算并锁账（LOCKED）时，强制将当前记账汇率快照写入订单记录；锁账后成本不可修改，后续汇率变动不影响已锁账订单利润
6. **缺货预警与一键采购（1688）**：
   - 缺货数量 = max(0, 订单需求数量 − 本地可用库存)
   - 缺货时订单状态旁高亮显示红色【缺货】标签，明细面板列出 SKU/需求数量/当前库存/缺货数量
   - 【一键生成采购单】自动提取缺货 SKU、绑定默认供应商及缺货数量，联动 purchase_orders 表
7. **订单状态流转**：待处理 → 已采购 → 已发货 → 已完成 → 退款售后

### 3.4 供应商管理模块（P0）
关联表：suppliers

1. **供应商档案**：名称、联系人、电话/微信、地址、结算周期、备注
2. **反向追溯**：供应商详情可查看其关联供应的所有本地商品列表

### 3.5 打印与导出模块（P0，集成 worm-vue3-print）
关联表：print_templates, print_queue, export_queue, order_planning_templates, order_word_templates

1. **打印引擎**：集成 worm-vue3-print（@worm-vue3-print/core@1.3.1 + canvas@1.3.1）
2. **模板自定义**：worm 可视化设计器拖拽设计，模板 JSON 存 print_templates.template_content
3. **四大单据场景**：订单标签/拣货单、采购订单、商业发票、订单规划书
4. **印章与 Logo 拖拽**：支持上传透明底 PNG 印章、JPG Logo，自由缩放、拖拽位置、Z-Index 图层、透明度/旋转
5. **导出格式**：订单支持导出 **PDF、Excel、docx** 三种格式，导出与页面筛选条件联动
6. **跨页能力**：多页 PDF 重复表头、页脚页码（1/2、2/2）、文档级页眉页脚
7. **异步大文件导出**：大导出走异步队列（导出后提供下载链接），不阻塞接口
8. **硬约束**：
   - 动态循环数组必须放 printData 顶层，dataSource 不支持嵌套路径
   - 服务端 PDF 导出使用 worm 官方 print-render 渲染微服务，禁止业务后端自行集成 Playwright
   - 渲染容器必须安装中文字体
   - 浏览器预览、浏览器打印、服务端 PDF 使用同一份模板和数据，三端一致

### 3.6 素材管理模块（P0）
关联表：materials

1. **云存储对接**：支持阿里云 OSS（预留腾讯云 COS 切换），配置 Endpoint、Bucket、AK/SK，提供"测试连接"
2. **硬限制**：单文件最大 10MB（前后端双重校验），超大阻断上传
3. **自动压缩**：图片上传时自动无损压缩，长边超过 1200px 等比缩放至 1200px（85% JPEG 质量），生成标准版/缩略图
4. **管理能力**：文件夹分类管理、图片预览、打标签（如"白底图""场景图"）、名称/日期筛选

### 3.7 数据同步中心模块（P0）
关联表：sync_jobs

1. **同步任务记录**：展示所有同步任务执行状态、失败原因、耗时
2. **定时自动同步**：订单、商品按可配置间隔自动轮询
3. **增量同步**：按时间范围增量拉取，避免全量重复
4. **失败重试**：单条失败可重试

### 3.8 汇率管理模块（P0）
关联表：exchange_rate_logs

1. **内部记账汇率**：管理员按币种（USD/EUR 等）手动录入"内部记账汇率"，精确到小数点后 4 位
2. **历史汇率**：记录汇率变更历史；成本、利润计算使用**订单下单时间对应的历史汇率**，不用实时汇率
3. **实时汇率参考**：可选展示中国银行外汇牌价作为调整内部记账汇率的决策参考

### 3.9 AI 审查模块（P1）
关联表：ai_gateway_configs, ai_inspection_jobs, ai_inspection_items, ai_inspection_results

1. **AI 中转站空壳网关**：系统不内置默认 API，用户必须在【系统设置 → AI 配置】自备填写 Base URL（OpenRouter、AI 杂货铺、自建代理等）和 API Key，测试通过后激活 AI 功能
2. **图片侵权审查**：商标侵权、Logo 侵权、违禁图检测（视觉模型）
3. **标题侵权审查**：文本合规审查（侵权品牌词、违禁词、极端夸大词、海关禁运品类）
4. **批量审查**：支持批量提交审查任务；审查结果可人工复核

### 3.10 系统配置模块（P1）
关联表：system_configs

1. **可视化配置页**：
   - 阿里开放平台配置（国际站/1688 appKey、appSecret）
   - 云存储 OSS 配置（Endpoint、Bucket、AK/SK）
   - AI 中转站配置（Base URL、API Key）
   - 素材限制配置（maxFileSize、thumbnailWidth）
   - 同步轮询间隔配置
2. **敏感字段**：密码输入框展示，留空保持原值，AES 加密存储

### 3.11 审计与安全（P1）
关联表：audit_events, operation_logs

1. **全量写操作审计**：所有 CUD 写操作（店铺绑定/解绑、订单成本修改、导出单据、上传素材、角色权限变更）记录操作人、时间、模块、动作类型、变更前后 JSON Diff、操作 IP
2. **敏感数据脱敏**：买家电话、邮箱、地址、供应商银行账号界面显示掩码（如 138****8888），仅专项解密权限用户经二次验证可查看明文

## 4. 技术架构

### 4.1 技术栈（已确认，禁止私自更换）
| 层 | 选型 | 版本/说明 |
|---|---|---|
| 后端 | RuoYi-Vue-Plus（Spring Boot 3/4 + Sa-Token + MyBatis-Plus） | v6.0.0，JDK21 |
| 前端 | vben-admin（Vue3 + TypeScript + Vite + Ant Design Vue） | main 分支 monorepo，apps/web-antd |
| 数据库 | PostgreSQL | 16.x |
| 缓存/队列 | Redis | 7.x |
| 打印 | @worm-vue3-print/core + canvas | 1.3.1（禁止 hiprint、禁止旧版 1.2.2） |
| PDF 渲染 | worm 官方 print-render 微服务 | Docker 部署，预装中文字体 fonts-wqy-zenhei |
| 云存储 | 阿里云 OSS SDK | 3.17.x（预留 COS 切换） |
| AI 网关 | OpenAI 兼容接口 /v1/chat/completions | RestTemplate 调用，不引入额外 SDK |
| 部署 | 宝塔面板 + Docker Compose | 服务器部署 |

### 4.2 系统架构分层
```
前端业务与应用层（vben-admin）
    ↓ /api 反向代理
核心业务逻辑层（RuoYi-Vue-Plus 业务模块）
    ├── 订单抓取与解析
    ├── 阶梯成本自动匹配
    ├── 多笔动态成本归集
    └── 内部汇率折算引擎（锁账快照）
基础设施与中台层
    ├── 素材中心 & 云存储（10MB/1200px）
    ├── AI 中转站空壳网关（自备 API Key）
    └── Worm 打印渲染服务
PostgreSQL + Redis 基础设施
```

### 4.3 第三方对接规范（详见 ali_sync 对接规范文档）
- 阿里国际站/1688：统一 AlibabaPlatformAdapter 接口，OAuth 授权、token 刷新、订单拉取
- 云存储：统一 StorageAdapter 接口，业务层不直接依赖 SDK
- AI 网关：统一 AiGatewayAdapter 接口，OpenAI 兼容
- Worm 打印：前端 PrintDesigner/PrintHtmlPreview，服务端官方渲染微服务
- 敏感凭证：独立 APP_ENCRYPTION_KEY 做 AES-256-GCM 加密，禁止复用 JWT_SECRET

## 6. 非功能需求

1. **财务数据精度**：所有金额字段 DECIMAL(12,4) 存储，前端展示四舍五入保留 2 位小数，累加导出账目准确
2. **凭证安全**：AES-256-GCM 加密存储，独立 APP_ENCRYPTION_KEY，禁止硬编码、禁止写日志、禁止返回前端
3. **数据处理性能**：订单拉取延迟控制在 3 分钟以内；10 万条数据级 Excel 报表异步队列导出，5 秒内生成并提供下载链接
4. **打印一致性**：浏览器预览、浏览器打印、服务端 PDF 三端渲染一致
