# 阿里国际站店铺授权实现文档（详细版）

> 适用范围：RuoYi-Vue-Plus 后端（Spring Boot + Sa-Token）+ vben-admin 前端
> 官方文档：https://open.alibaba.com（阿里巴巴开放平台）
> 关联文档：ali_sync 第三方对接规范、Ali-Sync PRD

---

## 1. 授权整体流程

```
前端店铺管理页
   ↓ 点击【添加阿里国际站店铺】
1. GET /api/shop/auth-url → 返回官方授权跳转地址
   ↓ 浏览器跳转
2. https://oauth.alibaba.com/authorize?response_type=code&client_id={app_key}&redirect_uri={回调地址}&state={随机state}
   ↓ 用户在阿里登录并授权
3. 阿里回调 → GET /api/shop/callback/ali1688?code=xxx&state=xxx
   ↓ 后端校验 state（Redis）
4. POST https://oauth.alibaba.com/token 用 code 换 access_token + refresh_token
   ↓
5. 调 com.alibaba.icbu.shop.get 获取 shopId / shopName
   ↓
6. AES-256-GCM 加密 token → 写入 stores 表
   ↓
7. 定时任务：token 过期前 7 天自动刷新
```

## 2. 官方接口清单

| 用途 | 接口 | 说明 |
|---|---|---|
| 授权跳转 | `https://oauth.alibaba.com/authorize?response_type=code&client_id={app_key}&redirect_uri={redirect_uri}&state={state}` | GET，浏览器跳转 |
| 换取 Token | `POST https://oauth.alibaba.com/token` | Form 参数：grant_type=authorization_code, code, client_id, client_secret, redirect_uri |
| 刷新 Token | `POST https://oauth.alibaba.com/token` | Form 参数：grant_type=refresh_token, refresh_token, client_id, client_secret |
| 获取店铺信息 | `com.alibaba.icbu.shop.get` | 通过 access_token 获取 shopId、shopName |
| 拉取订单 | `alibaba.icbu.trade.order.list.get` | 分页拉取订单（同步中心使用） |

**Token 响应字段：**
```json
{
  "access_token": "xxx",
  "refresh_token": "xxx",
  "expires_in": 86400,
  "ali_id": "卖家标识"
}
```

## 3. 数据库表设计（stores 表相关字段）

```sql
-- 店铺表（核心字段）
CREATE TABLE stores (
    id                BIGSERIAL PRIMARY KEY,
    platform          VARCHAR(20)  NOT NULL DEFAULT 'ALIBABA_INTL',  -- 平台标识
    shop_name         VARCHAR(200),                                    -- 店铺名称
    shop_id           VARCHAR(100),                                    -- 阿里店铺原始ID
    app_key           VARCHAR(100),                                    -- 应用Key（AES加密）
    app_secret        VARCHAR(200),                                    -- 应用密钥（AES加密）
    access_token      TEXT,                                            -- 访问Token（AES加密）
    refresh_token     TEXT,                                            -- 刷新Token（AES加密）
    token_expires_at  TIMESTAMP,                                       -- Token到期时间
    auth_status       VARCHAR(20) DEFAULT 'AUTHORIZED',                -- 授权状态
    sub_account_id    BIGINT,                                          -- 绑定的ERP员工账号ID
    seller_admin_seq  VARCHAR(100),                                    -- 卖家标识
    raw_response      TEXT,                                            -- 授权原始响应（审计用）
    created_at        TIMESTAMP DEFAULT NOW(),
    updated_at        TIMESTAMP DEFAULT NOW()
);

-- OAuth state 表（防CSRF，也可用Redis）
CREATE TABLE alibaba_oauth_states (
    id         BIGSERIAL PRIMARY KEY,
    state      VARCHAR(64)  NOT NULL,
    app_key    VARCHAR(100),
    redirect_uri VARCHAR(500),
    created_at TIMESTAMP DEFAULT NOW(),
    expired_at TIMESTAMP   -- 600秒过期
);
```

## 5. 后端核心代码实现

### 5.1 适配器接口与实现

```java
// com.alisync.adapter.platform.AlibabaPlatformAdapter.java
public interface AlibabaPlatformAdapter {
    String buildAuthUrl(String redirectUri, String state);          // 生成授权跳转地址
    PlatformTokenDTO exchangeToken(String code, String redirectUri); // 授权码换Token
    PlatformTokenDTO refreshToken(String refreshToken);              // 刷新Token
    ShopInfoDTO getShopInfo(String accessToken);                     // 获取店铺信息
    PlatformTypeEnum getPlatformType();
}
```

```java
// com.alisync.adapter.platform.impl.AlibabaIntlAdapterImpl.java
@Slf4j
@Component
public class AlibabaIntlAdapterImpl implements AlibabaPlatformAdapter {

    @Value("${alisync.platform.intl.app-key}")
    private String appKey;

    @Value("${alisync.platform.intl.app-secret}")
    private String appSecret;

    @Value("${alisync.platform.intl.auth-url}")
    private String authUrl;

    @Value("${alisync.platform.intl.token-url}")
    private String tokenUrl;

    @Value("${alisync.platform.intl.openapi-url}")
    private String openapiUrl;

    private final RestTemplate restTemplate = new RestTemplate();

    @Override
    public PlatformTypeEnum getPlatformType() {
        return PlatformTypeEnum.ALIBABA_INTL;
    }

    /**
     * 生成授权跳转地址
     * @param redirectUri 回调地址（必须与开放平台配置完全一致）
     * @param state 防CSRF随机串
     */
    @Override
    public String buildAuthUrl(String redirectUri, String state) {
        return String.format(
            "%s?response_type=code&client_id=%s&redirect_uri=%s&state=%s",
            authUrl, appKey, URLEncoder.encode(redirectUri, StandardCharsets.UTF_8), state);
    }

    /**
     * 授权码换Token
     * 业务约束：code 一次性有效，换完立即失效；失败要记录原始响应审计
     */
    @Override
    public PlatformTokenDTO exchangeToken(String code, String redirectUri) {
        MultiValueMap<String, String> params = new LinkedMultiValueMap<>();
        params.add("grant_type", "authorization_code");
        params.add("code", code);
        params.add("client_id", appKey);
        params.add("client_secret", appSecret);
        params.add("redirect_uri", redirectUri);
        return requestToken(params);
    }

    /**
     * 刷新Token
     * 业务约束：refresh_token 过期后必须引导用户重新授权
     */
    @Override
    public PlatformTokenDTO refreshToken(String refreshToken) {
        MultiValueMap<String, String> params = new LinkedMultiValueMap<>();
        params.add("grant_type", "refresh_token");
        params.add("refresh_token", refreshToken);
        params.add("client_id", appKey);
        params.add("client_secret", appSecret);
        return requestToken(params);
    }

    private PlatformTokenDTO requestToken(MultiValueMap<String, String> params) {
        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_FORM_URLENCODED);
        HttpEntity<MultiValueMap<String, String>> request = new HttpEntity<>(params, headers);

        ResponseEntity<String> response = restTemplate.postForEntity(tokenUrl, request, String.class);
        JSONObject json = JSON.parseObject(response.getBody());

        if (json.containsKey("error") || json.containsKey("error_code")) {
            log.error("阿里国际站OAuth失败: {}, 原始响应: {}", json, response.getBody());
            throw new ServiceException("阿里国际站授权失败: " + json.getString("error_description"));
        }

        PlatformTokenDTO dto = new PlatformTokenDTO();
        dto.setAccessToken(json.getString("access_token"));
        dto.setRefreshToken(json.getString("refresh_token"));
        dto.setExpiresInSeconds(json.getLong("expires_in"));
        dto.setTokenExpiresAt(LocalDateTime.now().plusSeconds(dto.getExpiresInSeconds()));
        dto.setSellerAdminSeq(json.getString("ali_id"));
        dto.setRawResponseJson(response.getBody());
        return dto;
    }

    /**
     * 获取店铺信息（com.alibaba.icbu.shop.get）
     */
    @Override
    public ShopInfoDTO getShopInfo(String accessToken) {
        MultiValueMap<String, String> body = new LinkedMultiValueMap<>();
        body.add("method", "com.alibaba.icbu.shop.get");
        body.add("app_key", appKey);
        body.add("session", accessToken);
        body.add("format", "json");
        body.add("v", "2.0");

        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_FORM_URLENCODED);
        HttpEntity<MultiValueMap<String, String>> request = new HttpEntity<>(body, headers);

        ResponseEntity<String> response = restTemplate.postForEntity(openapiUrl, request, String.class);
        JSONObject root = JSON.parseObject(response.getBody());

        JSONObject result = root.getJSONObject("result");
        ShopInfoDTO shop = new ShopInfoDTO();
        shop.setShopId(result.getString("shopId"));
        shop.setShopName(result.getString("shopName"));
        return shop;
    }
}
```

### 5.2 OAuth 回调 Controller（含 Redis state 校验）

```java
// com.alisync.module.shop.controller.ShopOAuthController.java
@Slf4j
@RestController
@RequestMapping("/api/shop")
@RequiredArgsConstructor
public class ShopOAuthController {

    private final ShopAuthorizationService shopAuthorizationService;

    /**
     * 获取授权跳转地址
     * 前端点击【添加店铺】调用，返回官方授权URL
     */
    @SaCheckPermission("shop:auth")
    @GetMapping("/auth-url")
    public R<String> getAuthUrl(@RequestParam(required = false) String platform) {
        return R.ok(shopAuthorizationService.buildAuthUrl(platform));
    }

    /**
     * 阿里国际站 OAuth 回调
     * 注意：这是浏览器302跳转接口，不能要求登录态
     */
    @GetMapping("/callback/ali1688")
    public void ali1688Callback(@RequestParam String code,
                                @RequestParam String state,
                                HttpServletResponse response) throws IOException {
        try {
            shopAuthorizationService.handleCallback("ALIBABA_INTL", code, state);
            // 授权成功，跳回前端店铺管理页并提示成功
            response.sendRedirect("/shop?auth=success");
        } catch (Exception e) {
            log.error("店铺授权回调失败, state={}", state, e);
            response.sendRedirect("/shop?auth=fail&reason=" + URLEncoder.encode(e.getMessage(), "UTF-8"));
        }
    }
}
```

### 5.3 授权核心 Service

```java
// com.alisync.module.shop.service.ShopAuthorizationService.java
@Slf4j
@Service
@RequiredArgsConstructor
public class ShopAuthorizationService {

    private final AlibabaPlatformAdapter alibabaPlatformAdapter;
    private final StringRedisTemplate redisTemplate;   // state 存 Redis
    private final StoreMapper storeMapper;
    private final AesCryptoUtil aesCryptoUtil;

    private static final long STATE_TTL_SECONDS = 600; // state 有效期600秒

    /**
     * 生成授权地址 + 保存 state 到 Redis
     * state 用途：防CSRF，回调时校验是否本次发起
     */
    public String buildAuthUrl(String platform) {
        String state = UUID.randomUUID().toString().replace("-", "");
        String redirectUri = getRedirectUri(platform);

        // state 存 Redis，600秒过期
        redisTemplate.opsForValue().set(
            "ali_oauth_state:" + state,
            platform,
            STATE_TTL_SECONDS, TimeUnit.SECONDS);

        return alibabaPlatformAdapter.buildAuthUrl(redirectUri, state);
    }

    /**
     * 回调处理：校验state → 换token → 查店铺 → 加密入库
     * 业务约束：
     * 1. state 校验失败直接拒绝（防CSRF）
     * 2. token 必须 AES 加密后存储，禁止明文
     * 3. 回调成功/失败后立即删除 state
     */
    @Transactional(rollbackFor = Exception.class)
    public void handleCallback(String platform, String code, String state) {
        // 1. 校验 state
        String stateKey = "ali_oauth_state:" + state;
        String savedPlatform = redisTemplate.opsForValue().get(stateKey);
        if (savedPlatform == null) {
            throw new ServiceException("state 无效或已过期，请重新发起授权");
        }
        // 校验通过立即删除，防重放
        redisTemplate.delete(stateKey);

        // 2. 换 token
        String redirectUri = getRedirectUri(platform);
        PlatformTokenDTO token = alibabaPlatformAdapter.exchangeToken(code, redirectUri);

        // 3. 查店铺信息
        ShopInfoDTO shopInfo = alibabaPlatformAdapter.getShopInfo(token.getAccessToken());

        // 4. 加密后入库（AES-256-GCM）
        Store store = new Store();
        store.setPlatform(platform);
        store.setShopId(shopInfo.getShopId());
        store.setShopName(shopInfo.getShopName());
        store.setAccessToken(aesCryptoUtil.encrypt(token.getAccessToken()));
        store.setRefreshToken(aesCryptoUtil.encrypt(token.getRefreshToken()));
        store.setTokenExpiresAt(token.getTokenExpiresAt());
        store.setSellerAdminSeq(token.getSellerAdminSeq());
        store.setAuthStatus("AUTHORIZED");
        storeMapper.insert(store);

        // 5. 写审计日志
        auditService.record("店铺授权", store.getId());
    }

    /**
     * 店铺列表（返回给前端时脱敏：禁止返回 token/密钥）
     */
    public List<StoreVO> listStores() {
        return storeMapper.selectList(null).stream().map(store -> {
            StoreVO vo = new StoreVO();
            vo.setId(store.getId());
            vo.setPlatform(store.getPlatform());
            vo.setShopName(store.getShopName());
            vo.setShopId(store.getShopId());
            vo.setAuthStatus(store.getAuthStatus());
            vo.setTokenExpiresAt(store.getTokenExpiresAt());
            // 注意：不 set accessToken / refreshToken / appSecret！
            return vo;
        }).toList();
    }

    /**
     * 解绑店铺：删除店铺记录 + token 立即失效
     */
    @Transactional(rollbackFor = Exception.class)
    public void unbindStore(Long storeId) {
        storeMapper.deleteById(storeId);
        auditService.record("解绑店铺", storeId);
    }
}
```

## 6. Token 自动刷新定时任务

```java
// com.alisync.module.shop.job.TokenRefreshJob.java
@Slf4j
@Component
@RequiredArgsConstructor
public class TokenRefreshJob {

    private final StoreMapper storeMapper;
    private final AlibabaPlatformAdapter alibabaPlatformAdapter;
    private final AesCryptoUtil aesCryptoUtil;

    /**
     * 每天凌晨 2 点执行：扫描即将过期（7天内）或已过期的店铺token并刷新
     * 定时表达式：@Scheduled(cron = "0 0 2 * * ?")
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void refreshExpiringTokens() {
        LocalDateTime threshold = LocalDateTime.now().plusDays(7);
        List<Store> expiringStores = storeMapper.selectList(
            new LambdaQueryWrapper<Store>()
                .eq(Store::getAuthStatus, "AUTHORIZED")
                .le(Store::getTokenExpiresAt, threshold));

        for (Store store : expiringStores) {
            try {
                String refreshToken = aesCryptoUtil.decrypt(store.getRefreshToken());
                PlatformTokenDTO newToken = alibabaPlatformAdapter.refreshToken(refreshToken);

                // 更新加密后的新token
                store.setAccessToken(aesCryptoUtil.encrypt(newToken.getAccessToken()));
                store.setRefreshToken(aesCryptoUtil.encrypt(newToken.getRefreshToken()));
                store.setTokenExpiresAt(newToken.getTokenExpiresAt());
                store.setAuthStatus("AUTHORIZED");
                storeMapper.updateById(store);
                log.info("店铺token刷新成功, storeId={}", store.getId());
            } catch (Exception e) {
                // 刷新失败标记 REFRESH_FAILED，前端提示重新授权
                store.setAuthStatus("REFRESH_FAILED");
                storeMapper.updateById(store);
                log.error("店铺token刷新失败, storeId={}", store.getId(), e);
            }
        }
    }
}
```

## 8. 授权状态机

| 状态 | 含义 | 触发 |
|---|---|---|
| AUTHORIZED | 授权正常 | 授权成功 / 刷新成功 |
| REFRESH_FAILED | Token刷新失败 | 定时任务刷新异常 |
| EXPIRED | Token已过期 | 超过到期时间未刷新 |
| UNBOUND | 已解绑 | 解绑操作 |

前端展示：AUTHORIZED 绿色、REFRESH_FAILED 红色（提示重新授权）、EXPIRED 橙色。

## 9. 安全要求（硬约束）

1. **凭证加密**：access_token、refresh_token、app_secret 使用独立 APP_ENCRYPTION_KEY（AES-256-GCM）加密存储，禁止复用 JWT_SECRET。
2. **禁止输出**：店铺列表接口、日志、异常信息中禁止出现任何 token/密钥明文。
3. **state 防 CSRF**：state 必须随机生成、Redis 存储、600秒过期、使用后立即删除。
4. **回调地址一致性**：授权时传入的 redirect_uri 必须与开放平台后台配置的完全一致（含域名、路径、https），否则授权失败。
5. **token 刷新失败处理**：连续失败标记 REFRESH_FAILED 并提示用户重新授权，禁止无限重试。
6. **审计日志**：授权、解绑、重新授权、token刷新全部记录操作人、时间、店铺ID。
